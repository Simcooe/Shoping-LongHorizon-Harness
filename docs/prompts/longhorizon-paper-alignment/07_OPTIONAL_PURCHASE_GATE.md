# 可选阶段7：购买前门禁的独立消融

## 定位与前置

这是购物场景扩展，不是LongHorizon-Harness论文要求的核心协议。
阶段1-6核心版本已验收并冻结后才实施；独立配置，例如
`mea-v4-paper-gated`，基础 `mea-v4-paper` 默认关闭。

## 运行许可

准备商品/规格 -> Auditor独立核验 -> 记录运行许可 -> Executor执行匹配的Buy Now
-> 环境终止 -> 最终只读审计。

运行许可不等于用户授权，也不代表已成交。至少绑定product、options、实际公开价格、
可确认的包装数量、requirement_version、环境选择版本、audit证据及使用状态。
许可生成本身不能让购买目标标为completed；只有成交后实际证据可以支持这一结论。

检查并失效：

- 没有许可或当前选择不匹配时拒绝Buy Now；
- 新需求、商品/规格/价格发生实质变化时重新核验；
- controller写日志、只读inspect不能仅因时间戳变化而让许可失效；
- 一次消费后不可重用；响应不明时按阶段5恢复协议核对，禁止直接重发；
- 工具不支持数量设置时，单支价格乘100不能生成“买100支”的许可。

## 验收与实验

用固定fixture验证单支/百支、价格拒绝、有效许可、实质状态变化、重复提交和未知响应。
